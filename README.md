# Service Inventory Lookup

A lightweight web page for finding a Government of Canada service inventory ID by
department and service name. A live version is available
[here](https://service-inventory-lookup.gcorgs.cdssandbox.xyz/en) et en français 
[ici](https://service-inventory-lookup.gcorgs.cdssandbox.xyz/fr).

## How it works

The page (`lookup_en.html` or `lookup_fr.html` plus `lookup.js`) loads `services.json` 
and provides type-ahead search: pick a department, then search its services to get the
service inventory ID, the bilingual service names, the organization and gc_orgID, and 
any associated program IDs. Many services do not have program IDs associated with them.

`services.json` is generated by `update_data.py`, which:

1. Pulls the [service ID registry](https://raw.githubusercontent.com/gcperformance/utilities/master/goc-service-id-registry.csv)
   and the parallel [service/program list](https://raw.githubusercontent.com/gcperformance/utilities/master/goc-service-program.csv).
2. Drops transferred and placeholder services.
3. Resolves each department to a canonical organization ID, bilingual name, and
   acronym via the [gcorg-resolver](https://www.github.com/cds-snc/gcorg_resolver) API.
4. Writes the combined records, plus a `generated_at` timestamp, to `services.json`.

The data are refreshed automatically every Monday.

lookups that you perform with this tool. If you notice anything that doesn't seem right,
