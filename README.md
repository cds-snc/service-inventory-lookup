# Service Inventory and Program Code Lookup

Two simple web pages for finding Government of Canada identifiers by
department:

- **Service Inventory Lookup** - finds a service inventory ID by department
  and service name
  ([en](https://service-inventory-lookup.gcorgs.cdssandbox.xyz/en) /
  [fr](https://service-inventory-lookup.gcorgs.cdssandbox.xyz/fr))
- **Program Code Lookup** - finds a program code identifier by department and program 
   name
  ([en](https://program-code-lookup.gcorgs.cdssandbox.xyz/en) /
  [fr](https://program-code-lookup.gcorgs.cdssandbox.xyz/fr))

## How They Work

### Service Inventory Lookup

The page (`service_en.html` or `service_fr.html` plus `service.js`) loads `services.json` 
and provides type-ahead search: pick a department, then search its services to get the
service inventory ID, the bilingual service names, the organization and gc_orgID, and 
any associated program IDs. Many services do not have program IDs associated with them.

`services.json` is generated by `update_services.py`, which:

1. Pulls the [service ID registry](https://raw.githubusercontent.com/gcperformance/utilities/master/goc-service-id-registry.csv)
   and the parallel [service/program list](https://raw.githubusercontent.com/gcperformance/utilities/master/goc-service-program.csv).
2. Drops transferred and placeholder services.
3. Resolves each department to a canonical organization ID, bilingual name, and
   acronym via the [gcorg-resolver](https://www.github.com/cds-snc/gcorg_resolver) API.
4. Writes the combined records, plus a `generated_at` timestamp, to `services.json`.

### Program Code Lookup

The page (`program_en.html` or `program_fr.html` plus `program.js`) loads
`program_codes.json` and provides the same style of type-ahead search pattern: pick a
department, then search its programs by name or code (e.g. `BWN01`) to get the
composed program code identifier, the bilingual program and core-responsibility
names, and the department and gc_orgID.

`program_codes.json` is generated by `update_programs.py`, which:

1. Pulls the EN and FR [Program codes list](https://open.canada.ca/data/en/dataset/3c371e57-d487-49fa-bb0d-352ae8dd6e4e)
   from the Government-wide Chart of Accounts, published by PSPC.
2. Filters each to Program Inventory rows (drops core-responsibility rows and
   entities with no programs).
3. Resolves each department to a canonical organization ID, bilingual name,
   and acronym via the [gcorg-resolver](https://www.github.com/cds-snc/gcorg_resolver) API.
4. Joins the EN and FR rows and composes `program_code_id = f"{gc_orgID}-{prog}"`.
5. Writes the combined records, a `generated_at` timestamp, and a `source` block
   (fiscal year, dataset URL, CSV URLs), to `program_codes.json`.

We intentionally append a organization identifier to the front of each program code, 
since some program codes are reused between different departments. For more details
on how we do that, see [this specification](docs/program-codes-spec.md).

The source CSV URLs and fiscal year are pinned to a specific year via hardcoded
constants (`PROGRAM_CODES_EN_URL`, `PROGRAM_CODES_FR_URL`, `SOURCE_FISCAL_YEAR`
in `update_programs.py`). When a new list of program codes is released, this data
source will be updated intentionally.

Both data sources are refreshed automatically every Monday.

## Status

This project is feature complete, but hasn't been rigorously tested. Please validate any
lookups that you perform with this tool. If you notice anything that doesn't seem right, 
reach out to [Colin](mailto:colin.douglas@cds-snc.ca) and we can figure it out.
